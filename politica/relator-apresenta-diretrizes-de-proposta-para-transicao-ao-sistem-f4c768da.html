Relator apresenta diretrizes de proposta para transição ao sistema de voto distrital misto

O deputado Domingos Neto apresentou as diretrizes de uma proposta para alterar o atual sistema proporcional de votação para o modelo distrital misto no país. O objetivo é votar a mudança no ano corrente, com implementação prevista para eleições municipais e gerais futuras.

Em poucas palavras
  • A proposta prevê voto único por eleitor para o sistema distrital e de lista partidária.
  • A mudança afeta a Câmara Federal, assembleias estaduais e distrital, além de câmaras de vereadores.
  • Municípios com mais de 200 mil eleitores seriam submetidos ao sistema distrital misto.

Diretrizes e cronograma

O relator apresentou as novas regras na Associação Comercial de São Paulo. A intenção é que a votação ocorra no ano corrente. A implementação do novo sistema está projetada para as eleições municipais e para as eleições gerais. Uma regra de transição para votações anteriores ainda está em debate pelos parlamentares.

Funcionamento do voto

O projeto estabelece um voto único para o eleitor, que servirá tanto para candidatos do distrito quanto para a lista partidária. As vagas de lista fechada serão definidas com base no somatório dos votos que cada partido obtiver em todos os distritos do estado. Municípios com mais de 200 mil eleitores adotariam o modelo, enquanto os demais manteriam a votação proporcional.

Critérios e regras dos distritos

Para evitar a manipulação de limites territoriais, os distritos deverão ser definidos com base em dados do censo, permitindo variação de 5% a 10% no total de eleitores entre os territórios. Os distritos devem ser contínuos e respeitar limites municipais. A lista fechada dos partidos também incluirá regras para intercalar a participação de homens e mulheres.
